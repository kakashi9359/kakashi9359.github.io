Nudge

A to-do assistant for procrastinators that messages you first, instead of waiting to be opened.

Role
Solo build
Status
Live
Stack
Python, Claude API, SQLite
Code
GitHub

The problem

Productivity apps only work if you remember to open them. For people who procrastinate, that's the step that fails.

Interruption beats intention.

Approach

Nudge lives in Telegram, which is already on your phone. It checks in every morning and evening and manages tasks through normal conversation.

  • Conversation Claude Sonnet decides when to add, update or finish tasks using tool calls.
  • Scheduling APScheduler, with jobs saved in SQLite so they survive restarts.
  • Hosting Railway, with a persistent volume for the database.
bot/ handlers.py Telegram messages claude.py Claude API calls tools.py task tools Claude can call scheduler.py morning and evening pings database.py SQLite access

What was hard

  • Missed morning pings. Scheduled messages sometimes didn't fire. Logging on each job showed where they failed.
  • Network blocking. My ISP blocked Telegram's API, which looked like a code bug until I tested on a mobile hotspot.

Result

Deployed and running daily.

Next

  • Reminders set in plain language, like "remind me Friday at 3".
  • Showing one task at a time when the list gets long.
  • Flagging tasks that keep getting skipped.
